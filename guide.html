VINYL 사용 설명서

유튜브 음악을 진짜 LP처럼 듣는 웹앱입니다. 곡을 틀면 가운데에서 검은 판이 돌고, 바늘이 바깥 홈에서 시작해 안쪽으로 들어갑니다. 설치는 없습니다 — 주소만 열면 됩니다.

  • iPhone · Safari
  • iPad · Galaxy · 데스크톱
  • 화면은 iOS 기준
1

처음 열면

주소를 열면 빈 턴테이블이 기다리고 있습니다. 곡을 하나도 넣지 않은 상태예요.

매번 주소를 치기 번거로우니 홈 화면에 추가해 두세요. 공유 버튼 → 홈 화면에 추가를 고르면 아이콘이 생기고, 그 아이콘으로 열면 주소창 없이 화면 전체를 씁니다.

먼저 알아두기

홈 화면에 추가할 때 웹 앱으로 열기를 켜면 주소창이 사라지는 대신 사파리와 로그인이 분리됩니다. 유튜브 프리미엄을 쓰신다면 8번을 먼저 읽어보세요.

2

곡 넣기

유튜브에서 듣고 싶은 곡의 공유 → 복사를 누르고, VINYL에서 오른쪽 위 ＋ 추가를 누릅니다. 복사해 둔 링크를 알아서 읽어 판을 만듭니다.

클립보드를 못 읽는 경우엔 입력창이 열립니다. 거기에 링크를 붙여넣고 ＋를 누르면 같습니다.

영상 하나든 재생목록이든 상관없습니다. 재생목록 링크를 넣으면 그 안의 곡이 한꺼번에 들어옵니다.

3

듣기

판이 돌기 시작하면 배경이 그 앨범의 색으로 물듭니다. 조작은 전부 판 위에서 합니다.

4

선반에서 고르기

왼쪽 선반에 모아 둔 앨범이 꽂혀 있습니다. 앨범을 톡 누르면 그 곡이 재생됩니다.

선반은 왼쪽 가장자리 손잡이로 여닫습니다. 화면 맨 왼쪽에서 오른쪽으로 밀면 열리고, 손잡이 근처에서 왼쪽으로 밀면 닫힙니다.

앨범을 왼쪽으로 쭉 밀면 빨갛게 변하고, 손을 떼면 지워집니다. 살짝만 밀면 제자리로 돌아오니 실수할 걱정은 없습니다.

5

앨범 보기와 순서 바꾸기

화면 아래 가운데의 격자 버튼을 누르면 앨범이 한눈에 깔립니다. 여기서 눌러도 재생됩니다.

오른쪽 위 편집을 누르면 앨범이 살짝 흔들립니다. 이 상태에서 꾹 잡고 끌어 순서를 바꾸고, 왼쪽 위 ×로 지웁니다. 빈 곳을 누르면 편집이 끝납니다.

편집 중에 앨범을 위쪽 재생목록 이름 위로 끌어다 놓으면 그 목록으로 복사됩니다. 원본은 그대로 남습니다.

6

재생목록

화면 위쪽 알약이 재생목록입니다. 이름을 눌러 목록 사이를 오가고, 옆의 ＋로 새 목록을 만듭니다. 개수 제한은 없습니다.

목록이 많아 옆으로 넘쳐도, 지금 듣고 있는 목록이 항상 가운데로 옵니다.

7

⋯ 메뉴

오른쪽 위 ⋯에 나머지가 전부 들어 있습니다.

항목하는 일
재생목록 이름 바꾸기지금 목록의 이름을 고칩니다

백업 파일 저장 · 불러오기파일로 내려받아 두고 나중에 되살립니다

8

광고 없이 듣기

광고가 붙는 건 로그인을 안 해서가 아니라, 브라우저가 남의 사이트에 끼워 넣은 유튜브 창에 로그인 정보를 넘겨주지 않기 때문입니다. 그래서 기기마다 방법이 다릅니다.

아이폰 · 아이패드 — 설정 → 앱 → Safari → 고급에서 크로스 사이트 추적 방지를 끈 다음, 메뉴에서 유튜브에 로그인합니다. 홈 화면 아이콘으로 쓰신다면 아이콘은 사파리와 로그인이 분리돼 있어 앱 안에서 한 번 더 로그인해야 하고, 로그인 뒤에는 앱을 완전히 종료했다가 다시 열어야 합니다.

갤럭시 · 안드로이드 — 크롬으로 유튜브에 로그인만 해두면 끝입니다. 설정을 바꿀 필요도, 앱 안에서 다시 로그인할 필요도 없습니다.

9

가로로 눕히면

폰을 가로로 돌리면 배치가 바뀝니다. 판이 오른쪽으로 가고, 왼쪽에 곡 제목과 재생 버튼이 세로로 모입니다. 판을 크게 보면서 조작하기 좋습니다.

알아두면 좋은 것

목록은 기기마다 따로 저장됩니다
아이패드에서 모은 목록이 아이폰에 자동으로 생기지는 않습니다. ⋯ 메뉴의 공유 링크 복사로 주소를 보내거나, 백업 파일로 옮기세요.
다른 앱에 갔다 오면 소리가 끊깁니다
아이폰과 아이패드는 웹앱이 뒤로 가면 소리를 끕니다. 막을 방법이 없습니다. 대신 돌아오면 끊긴 지점에서 이어집니다.
어떤 곡은 재생이 안 됩니다
일부 영상은 올린 사람이 외부 재생을 막아 뒀습니다. 그런 곡은 안내가 뜨고 자동으로 다음 곡으로 넘어갑니다. 같은 곡의 다른 영상을 넣으면 대개 됩니다.
주소는 http 또는 https 로 열어야 합니다
파일을 직접 열면(file://) 유튜브가 재생을 막습니다.
뭔가 이상할 때
선반 위쪽의 재생목록 이름을 세 번 연속 두드리면 화면 왼쪽 아래에 상태 정보가 나옵니다. 그 화면을 캡처해 두면 원인을 찾는 데 도움이 됩니다.
