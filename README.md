# VINYL

유튜브 음악을 진짜 LP판처럼 들려주는 앱입니다.

곡을 틀면 화면 가운데에서 검은 판이 돌아가고, 바늘이 바깥쪽 홈에서 시작해 노래가 진행될수록 안쪽으로 조금씩 들어갑니다. 배경은 그 앨범의 색으로 물들고, 왼쪽에는 내가 모은 앨범들이 선반에 꽂혀 있습니다.

아이패드 가로 화면에서 가장 예쁘지만 아이폰과 안드로이드 폰에서도 쓸 수 있습니다.

---

## 1. 시작하기

### 앱 주소 열기

전달받은 주소를 사파리에서 엽니다.

### 홈 화면에 추가하기 (권장)

주소를 연 상태에서 화면 위쪽 **공유 버튼**(네모에 화살표)을 누르고 **홈 화면에 추가**를 선택합니다. 바탕화면에 VINYL 아이콘이 생기고, 그 아이콘으로 열면 주소창과 탭 없이 화면 전체를 씁니다. 진짜 앱처럼요.

---

## 2. 노래 넣기

1. 유튜브나 유튜브 뮤직에서 듣고 싶은 곡을 찾습니다
2. **공유 → 복사**를 누릅니다
3. VINYL로 돌아와 오른쪽 위 **＋ 추가**를 누릅니다

끝입니다. 복사해 둔 링크를 알아서 읽어서 판이 만들어집니다. 뭔가 입력할 필요도, 키보드가 뜰 일도 없습니다.

앨범이나 재생목록 링크를 넣으면 그 안의 곡이 한꺼번에 들어옵니다.

---

## 3. 음악 듣기

**왼쪽 선반에서 앨범을 톡 누르면** 그 곡이 재생됩니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 재생 / 멈춤 | 가운데 판을 누르기 |
| 다음 곡 / 이전 곡 | 판을 왼쪽 또는 오른쪽으로 밀기 |
| 원하는 부분으로 이동 | 바늘(톤암)을 잡고 끌기 |
| 섞어 듣기 | 재생 버튼 왼쪽의 화살표 버튼 |
| 반복 듣기 | 재생 버튼 오른쪽 버튼. 누를 때마다 **끄기 → 전체 반복 → 한 곡 반복** |
| 선반 접기 | 선반 오른쪽 가장자리 가운데의 작은 손잡이 |

---

## 4. 정리하기

### 노래 지우기

선반에서 앨범을 **왼쪽으로 쭉 밀면** 빨갛게 변합니다. 그대로 손을 떼면 지워집니다. 살짝만 밀면 제자리로 돌아오니 실수할 걱정은 없습니다.

### 순서 바꾸기

1. 화면 아래 가운데의 **네모 격자 버튼**을 눌러 앨범 화면으로 갑니다
2. 오른쪽 위 **편집**을 누릅니다 (앨범들이 살짝 흔들립니다)
3. 앨범을 **꾹 잡고 원하는 자리로 끌어다 놓습니다**
4. 빈 곳을 누르면 편집이 끝납니다

편집 중에 앨범 왼쪽 위의 **×**를 누르면 그 곡이 지워집니다.

---

## 5. 재생목록 만들기

화면 위 가운데에 재생목록 이름이 있습니다. 옆의 **＋**를 누르면 새 목록이 만들어지고, 이름을 눌러 목록 사이를 오갈 수 있습니다. 개수 제한은 없습니다.

**다른 목록으로 곡 옮기기**는 앨범 화면에서 앨범을 꾹 잡아 위쪽 재생목록 이름 위로 끌어다 놓으면 됩니다. 원본은 그대로 남고 복사만 됩니다.

---

## 6. 취향대로 바꾸기

오른쪽 위 **⋯** 를 누르면 나오는 메뉴입니다.

**LP 색** — 동그라미 네 개 중에 고릅니다. 검정, 흰색, 투명, 그리고 앨범색입니다. 앨범색은 지금 듣는 곡의 앨범에서 색을 뽑아 컬러 LP를 만들어 줍니다.

**실물 음반 찾기** — 켜 두면 인터넷에서 그 곡의 진짜 LP나 CD 사진을 찾아 화면의 판을 그 사진으로 바꿔 줍니다. 못 찾으면 직접 그린 예쁜 라벨이 대신 들어갑니다.

**유튜브 화면 보이기 / 숨기기** — 소리가 나오는 작은 유튜브 창을 보이거나 감춥니다. 기본은 숨김입니다.

**재생목록 이름 바꾸기 · 삭제 · 다른 목록에 전체 복사**도 여기 있습니다.

---

## 7. 다른 기기에서도 쓰기

노래 목록은 기기마다 따로 저장됩니다. 아이패드에서 모은 목록이 아이폰에는 없습니다.

**옮기는 방법**은 ⋯ 메뉴의 **공유 링크 복사**입니다. 복사된 주소를 카톡이나 메모로 다른 기기에 보내고 거기서 열면 목록이 그대로 생깁니다.

**백업**은 ⋯ 메뉴의 **백업 파일 저장**입니다. 파일 하나가 저장되는데, 나중에 **백업 파일 불러오기**로 되살릴 수 있습니다. 사파리 기록을 지워도 이 파일만 있으면 안전합니다.

## 알아두면 좋은 것

**소리가 안 나요** — 이 앱은 반드시 `http://` 또는 `https://` 로 시작하는 주소에서 열어야 합니다. 파일을 직접 열면 유튜브가 재생을 막습니다.

**다른 앱 갔다 오면 음악이 끊겨요** — 아이폰과 아이패드는 웹앱이 뒤로 가면 소리를 끕니다. 막을 방법이 없습니다. 대신 돌아오면 끊긴 지점에서 이어집니다.

**광고가 나와요** — 유튜브 프리미엄이 아니면 곡 앞에 광고가 붙습니다. 광고일 때는 유튜브 화면이 자동으로 잠깐 나타나니 건너뛰기를 누르면 됩니다.

**어떤 곡은 재생이 안 돼요** — 일부 곡은 외부 앱에서 틀 수 없게 막혀 있습니다. 그런 곡은 안내가 뜨고 자동으로 다음 곡으로 넘어갑니다.

**뭔가 이상해요** — 선반 위쪽의 CRATE 글씨를 세 번 연속 두드리면 화면 왼쪽 아래에 상태 정보가 나옵니다. 그 화면을 캡처해서 보여 주시면 원인을 찾는 데 큰 도움이 됩니다.
